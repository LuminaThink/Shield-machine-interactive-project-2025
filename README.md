# 盾构机渣土状态监测系统
![alt text](<盾构机渣土状态监测系统 - 项目方案-图片-1-1.jpg-1.jpg>)

## 项目概述
本项目针对盾构机施工中渣土状态监测的关键需求，设计了一套基于温湿度传感器的智能监测系统。在盾构施工过程中，渣土的干湿状态直接影响施工安全、效率和刀具寿命。传统的人工判断方法存在主观性强、响应滞后等问题。

本系统利用DHT11温湿度传感器实时监测土仓环境，通过ESP32主控板分析数据，并使用三色LED指示灯直观显示渣土状态（过干/理想/过湿），为操作人员提供实时反馈和工程建议。

## 技术平台
- ESP32 + 传感器 + AI算法
- 应用领域：盾构施工 / 隧道工程 / 智能监测

## 主要功能特点

### 📊 智能温湿度监测
- 实时采集土仓环境温度和湿度数据
- 使用DHT11高精度传感器，数据更新频率为2秒/次

### 🧠 渣土状态智能判断
- 基于温湿度阈值算法自动判断渣土状态
- 采用综合评分算法提高判断准确性

### 💡 三色LED状态指示
- 红色LED：表示过干状态（闪烁提醒）
- 绿色LED：表示理想状态（常亮）
- 蓝色LED：表示过湿状态（闪烁提醒）

### 💻 串口监控界面
- 提供详细的串口输出，显示实时数据
- 根据监测结果提供工程建议

### ⚠️ 异常状态预警
- 异常状态时LED闪烁提醒
- 传感器故障时提供特殊提示

### 🔍 系统自检功能
- 启动时执行自检并显示系统信息
- 确保设备正常运行

## 工作原理

系统以XIAO ESP32作为主控制器，连接DHT11温湿度传感器实时采集环境数据。控制器根据预设的温湿度阈值，通过综合评分算法判断渣土状态：

1. DHT11传感器每2秒采集一次温湿度数据
2. 系统对比采集数据与预设阈值（温度：干>30°C，湿<20°C；湿度：干<40%，湿>70%）
3. 采用综合评分算法：温度或湿度任一指标超标得1分，两项指标均显示干/湿则判定为相应状态
4. 根据判断结果控制对应LED指示灯
5. 系统同时通过串口输出详细状态信息、实时数据和工程建议

## 接线说明

### 硬件连接方式
- DHT11传感器 → GPIO2（数据引脚）
- 红色LED（过干）→ GPIO3，串联220Ω电阻到GND
- 绿色LED（理想）→ GPIO4，串联220Ω电阻到GND
- 蓝色LED（过湿）→ GPIO6，串联220Ω电阻到GND
- 所有组件共地连接

## 系统配置

### 软件环境配置
1. 安装Arduino IDE（版本1.8.x或以上）
2. 添加ESP32开发板支持：文件 → 首选项 → 附加开发板管理器网址添加：
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. 工具 → 开发板 → 开发板管理器，搜索安装"ESP32"
4. 安装DHT传感器库：项目 → 加载库 → 管理库，搜索安装"DHT sensor library"

## 使用说明

1. 按照接线说明连接硬件
2. 将代码上传至ESP32开发板
3. 打开串口监视器（波特率：115200）
4. 观察LED指示灯状态和串口输出信息
5. 根据系统提示调整渣土状态

## 故障排除
- **传感器无响应**：检查接线是否正确，确认DHT11传感器是否损坏
- **LED不亮**：检查LED极性和限流电阻连接
- **数据异常**：重启系统，检查传感器是否被遮挡或受干扰
